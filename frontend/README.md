# MusicDreamer-frontend

悦享音乐前端（Vue 3 + Vite + Element Plus + Pinia + WeUI 反馈层）。

## 快速开始

```bash
npm install        # 需 Node.js 18+
npm run dev        # Vite 开发服务器（默认 http://localhost:5173）
```

开发服务器已把 `/api`、`/ws`、`/data` 代理到本地网关 `http://localhost:8080`，请先启动后端 gateway 再调试。

```bash
npm run build      # 构建产物输出到 dist/
```
